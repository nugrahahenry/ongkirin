# Ongkirin

Dokumentasi proyek Flutter kalkulator ongkos kirim RajaOngkir untuk tugas Diego atau Sloth.

Profil dokumentasi yang dipakai adalah **Internal Tool**. Aplikasi lama `pengembangan_aplikasi_bergerak_ets` tetap terpisah dan tidak diubah.

Status saat ini adalah Draft. Tahap aktif mencakup scope, UX, API contract, state UI, dan design system. Implementasi Flutter dimulai setelah dokumen inti disetujui.

Urutan baca yang disarankan adalah Overview, Business, Product, Design, Technical, Quality, Operations, lalu User Guides.

Dokumen yang tidak berlaku untuk MVP adalah login pengguna, pembayaran, pelacakan AWB, pembuatan order, backend proxy, database server, dashboard admin, push notification, riwayat permanen, webhook, dan multi-tenant.

API key tidak boleh dimasukkan ke Git, screenshot, README, log, atau source code.
